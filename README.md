# tapsay
手机扫码就能变触摸板控制电脑的工具还能语音转文字vibe coding辅助神器
此前曾原创Windows电脑版和苹果电脑版的双版TapVox，都是辅助AI编程的神器。不过它俩都是先在手机上直接完成语音转文字最后发文字给电脑，我今天带来的是另一种实现方式直接就在电脑上完成语音转文字的TapSay。

TapSay专为居家瘫靠在椅背上折腾氛围编程（Vibe Coding）特别优化，添加了一个圆圆的可以随意移动位置的话筒图标，可以让你直接用嘴巴言无不尽的跟AI比如说在现在非常火爆的DeepSeek Harness电脑桌面版里详细说明你的要求，免除AI因为你给的文字信息量少而误解你的意思的乌龙！语音转文字就是轻点一下白话筒语音图标说话直接转文字，也就是点电脑可输入的任意光标处会显示你说的话转成的文字自动断句加标点符号。轻点白话筒图标一次后它可以持续收音，哪怕你中途睡了半小时醒来后可以直接说话语音转文字。直到你再点一次红话筒图标它变回最初的白话筒图标的不收音状态！


TapSay是一款轻量局域网控制工具。
运行TapSay.exe，自动弹出二维码。手机自带相机扫码（或者微信等有扫一扫功能的APP扫码也可以），手机扫码后二维码自动缩到系统托盘区后台运行，浏览器直接进入控制页面，不用下载任何配套手机APP。

✅ 触摸板：滑动移动光标，单指点击左键长按拖曳双击进入。双指点击实现轻点右键、滑动滚动滚轮（长按滚上或滚下按钮也是持续长滚滑轮）、捏合缩放。三指上下滑动切换清理桌面也就是把所有窗口最小化和恢复原状。三指轻点触摸板等于持续按住锁定CTRL键可以单击点选所需文件和文件夹再次三指轻点触摸板等于释放Ctrl键。三指左滑切换前一个窗口右滑切换后一个窗口。

✅ 屏幕左右侧边缘单指上滑/下滑：持续滚动鼠标滚轮向上/向下。

✅ 光标在字符前后的自由移动方法2（触摸板定位外的第二种方法）：剪贴板与下方按钮之间那条分隔线任意位置以及剪贴板图标按住左滑光标持续逐字往前，按住右滑光标持续逐字往后。

✅ 鼠标滚轮小浮岛：初始出现在屏幕右侧的边缘的鼠标滚轮向上，向下和中间滚轮键按钮的小浮岛可以自由移动摆放在任意位置，也可以右侧屏幕边缘贴边隐藏。

✅ 特色按钮：⌫按钮是向左删除功能长按是持续删除，两个窗口叠加按钮是窗口循环切换功能，ENT按钮是Enter回车功能键的简写。

✅ 点话筒说话转文字按回车后会截图发送到触摸板上可缩放和移动位置：截图上单指下滑刷新截图，左滑上滑隐藏到左边缘，隐藏后左边缘往右滑呼出。

✅ 剪贴板图标同步随心：Tap触摸板下方的中间新增一个剪贴板图标可以随时让电脑剪贴板里的文件和文字内容和手机双向获取。

✅ 虚拟键盘：手机直接向电脑输入文字。

✅ 纯局域网通信，数据只在本机和手机之间传输，不上外网。

✅ 单exe绿色免安装，支持PE环境临时操控电脑
适合演示、罹患鼠标手病症替代操控、PE维护(pe需要ws2_32.dll依赖文件)，应急没有鼠标和键盘以及触控板失效时使用。

总而言之，该工具手机上要语音有语音要鼠标有鼠标要触摸板有触摸板要键盘有键盘，还能和电脑互传文件和文本内容片段互通有无，TapSay.exe和TapVox一样也是全网效率最高的AI辅助编程神器，是氛围编程（Vibe Coding）时代的绝对主力之一。
